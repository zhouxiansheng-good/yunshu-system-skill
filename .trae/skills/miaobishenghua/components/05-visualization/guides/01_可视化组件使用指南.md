# 可视化拓扑组件 v3.0 使用指南

## 概述

可视化拓扑组件是「妙笔生花」的第四组件，通过可拖拽的网页拓扑图编辑器，让你直观地管理小说的人物关系、金手指成长、势力格局和章节结构。

**核心特性**：
- 🎨 拖拽式节点编辑，可视化搭建故事框架
- 👤⚡🏛️ L1层三模块：人物/金手指/势力独立管理
- 🔄 双向实时同步：网页改动 ↔ 文档改动
- 🏷️ 关系编辑：事件过程+关系变化+章节范围+确定机制
- 🌍 世界观背景板：根据小说类型切换画布背景
- 📝 L3正文层：双面板设计（编辑+词汇替换）
- 📸 自动归档历史版本

---

## 快速开始

### 1. 启用可视化组件

在项目根目录创建 `可视化配置.json`：

```json
{
  "enabled": true,
  "auto_sync": true,
  "sync_interval_ms": 500,
  "server_port": 3456,
  "worldview": "default"
}
```

### 2. 启动可视化服务

```bash
cd .trae/skills/妙笔生花/components/04-visualization/server
node server.js --project-root "你的项目路径" --port 3456
```

### 3. 打开编辑器

浏览器访问 `http://localhost:3456`

## 基本操作

### 添加节点

1. 点击工具栏「➕ 添加节点」
2. 选择节点类型（人物/金手指/势力）
3. 输入节点名称
4. 点击「✦ 创建节点」

### 添加连线（关系）

1. 点击工具栏「🔗 添加连线」
2. 点击源节点
3. 点击目标节点
4. 在弹窗中编辑关系：
   - 📖 **事件过程**：描述事件的发展过程（线上）
   - 🔄 **关系变化**：描述关系的变化，如"陌生人 → 好友"（线下）
   - 🏷️ **关系类型**：选择中立/友好/敌对/师徒/恋人/亲人/同盟/竞争
   - 📚 **章节范围**：设置关系从第几章到第几章
5. 点击「💾 保存关系」或「✅ 确定关系」

### 查看节点信息

1. **单击节点**打开信息弹窗
2. 查看基础信息（起点/终点状态、章节范围等）
3. 查看关联关系列表
4. 点击「✏️ 编辑节点」进入编辑模式

### 编辑节点

1. **双击节点**打开编辑面板
2. 修改节点名称、类型、备注
3. 修改模块专属属性：
   - **人物**：起点状态、终点状态
   - **金手指**：开始章节、结束章节、成长描述
   - **势力**：势力类型
4. 点击「💾 保存修改」

### 删除节点/连线

1. 选中节点或连线
2. 按 `Delete` 键，或点击「🗑️ 删除」
3. **注意**：删除关联文件的节点不会删除文件，仅删除拓扑图中的节点

## 关系编辑详解

### 关系编辑弹窗字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 事件过程 | 描述事件的发展过程 | 两人在酒馆相遇，因误会大打出手 |
| 关系变化 | 描述关系的变化 | 陌生人 → 敌对 → 和解 → 好友 |
| 关系类型 | 关系的性质 | 友好/敌对/师徒/恋人等 |
| 章节范围 | 关系存在的时间范围 | 第1章 ~ 第5章 |
| 关系标记 | 剧情标记 | 悬疑/反转/高潮/伏笔/因果/情感 |

### 按钮说明

| 按钮 | 功能 |
|------|------|
| 💾 保存关系 | 保存当前关系，confirmed=false |
| ✅ 确定关系 | 保存并确认关系，confirmed=true |
| ➕ 保存并继续 | 保存当前关系，不关闭弹窗，继续添加新关系 |

### 一个节点与多个节点建立关系

1. 选中源节点
2. 依次点击多个目标节点
3. 每次都会弹出关系编辑弹窗
4. 可以设置不同的关系类型和章节范围

## 双向同步机制

### 文档 → 网页（自动）

当你在 VS Code/Trae 中修改文档时：

| 操作 | 拓扑图响应 |
|------|-----------|
| 新建角色文件 | 自动新增人物节点 |
| 修改文件标题 | 自动更新节点名称 |
| 删除文件 | 节点标记「文件已删除」，不自动移除 |

**防抖机制**：文档变动后等待 500ms 再同步，避免频繁触发。

### 网页 → 文档（自动）

当你在拓扑图中操作时：

| 操作 | 文档响应 |
|------|---------|
| 修改节点名称 | 同步更新 `topology.json` |
| 拖拽节点位置 | 保存位置到 `topology.json` |
| 添加/删除节点 | 更新 `topology.json` |
| 添加/删除连线 | 更新 `topology.json` |

**注意**：网页上的节点名称修改**不会**反向修改原始文档的标题（避免意外覆盖）。如需修改文档，请直接编辑 `.md` 文件。

## 数据存储

### 拓扑数据

```
{project_root}/拓扑数据/
├── topology_L1.json    # 大纲层（含characters/cheats/forces）
├── topology_L2.json    # 细纲层（含chapters/characters/cheats/forces）
└── topology_L3.json    # 正文层
```

### 自动归档

每次关闭服务时，自动保存快照：

```
{project_root}/可视化快照/topology_YYYYMMDD_HHMMSS.json
```

保留最近 20 个快照，超出自动清理最旧的。

## 常见问题

### Q: 服务启动失败，提示端口被占用？
A: 修改 `可视化配置.json` 中的 `server_port` 为其他端口（如 3457），然后重新启动。

### Q: 网页显示「已断开」？
A: 检查服务是否正常运行，或刷新网页。服务会自动重连。

### Q: 删除文件后节点还在？
A: 这是设计如此。节点会标记「文件已删除」，你可以手动决定是否删除节点，避免误删导致拓扑结构丢失。

### Q: 能否在多台电脑上使用？
A: 目前设计为本地单机使用。如需多设备，可将项目目录放在云同步盘（如 OneDrive），但同一时间只能运行一个服务实例。

### Q: L1层的三个模块数据是独立的吗？
A: 是的，人物、金手指、势力三个模块有独立的节点和连线。切换模块时，画布会重新渲染显示对应模块的内容。

### Q: 如何查看一个人物的所有关系？
A: 单击人物节点打开信息弹窗，在「关联关系」区域会列出所有与该人物相关的关系，包括关系类型和章节范围。

## 与写作流程的集成

```
开新书
  ↓
组件一：项目初始化（创建骨架 + 可视化配置模板）
  ↓
组件二：作品拆解汇总
  ↓
组件三：正文写作
  ↓
组件四：可视化拓扑（随时打开，查看全局关系）
  - 写新章节前：查看人物关系，检查伏笔连接
  - 写章节时：标记悬疑点、高潮位置
  - 写完后：确认事件节点与章节细纲对应
  - 编辑正文时：使用L3层的词汇替换参考
```
