## 二、一句话梗概

一个被判定为"废灵根"的少年（主角）在家族灭门之夜（困境）获得"逆天改命系统"（目标），为了复仇和证明"废灵根也能成仙"（代价），不惜以燃烧寿命为代价强行突破（代价）。

## 三、核心卖点

| 卖点 | 说明 | 兑现章节 |
|------|------|---------|
| **爽点 1** | 废柴逆袭，打脸曾经嘲笑他的人 | 第10章、第30章 |
| **爽点 2** | 独特金手指：燃烧寿命换修为，越战越强 | 第1章获得，持续兑现 |
| **爽点 3** | 悬念钩子：灭门真凶到底是谁？ | 第50章揭示 |
| **差异化** | 不是无脑爽，每次突破都有真实代价 | 贯穿全书 |

## 四、四幕结构概览

| 幕 | 名称 | 核心事件 | 章节范围 |
|----|------|---------|---------|
| 第一幕 | 起（建局） | 家族灭门，主角获得系统，开始复仇之路 | 第1-50章 |
| 第二幕 | 承（升级） | 进入宗门，发现灭门背后有更大阴谋 | 第51-150章 |
| 第三幕 | 转（反转） | 发现系统本身就是阴谋的一部分 | 第151-250章 |
| 第四幕 | 合（终局） | 打破系统束缚，真正逆天改命 | 第251-300章 |

## 五、创作原则

- [x] **原则 1**：主角绝不主动作恶，即使复仇也保持底线
- [x] **原则 2**：反派必须有合理动机，不能为坏而坏
- [x] **原则 3**：每次使用系统都有真实代价，不能无限开挂
- [x] **原则 4**：每章必须有动作推进，禁止流水账
