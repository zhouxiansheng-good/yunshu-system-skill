# 世界观设定

## 一、核心规则

### 1.1 力量体系

- **体系名称**：九转玄功
- **修炼方式**：吸纳天地灵气，淬炼肉身与神魂
- **等级阶梯**：炼气→筑基→金丹→元婴→化神→渡劫→大乘→真仙→金仙
- **突破条件**：每阶需渡雷劫，雷劫强度与业力相关
- **核心资源**：灵石、丹药、法宝

### 1.2 世界基础设定

| 维度 | 设定 |
|------|------|
| **时间** | 天元历三千五百年 |
| **空间** | 三界：人界、灵界、仙界 |
| **物理规则** | 灵气存在，可修炼；天道有缺，渡劫九死一生 |
| **社会结构** | 宗门制，大宗门统治区域，小家族依附生存 |

## 三、势力分布

- **正道联盟**（友方/复杂）
  - 青云宗：主角起点，表面正派实则腐朽
  - 万佛寺：中立，不参与纷争
  - 天机阁：情报组织，可交易但代价高
- **魔道**（敌方）
  - 血魔宗：主要反派势力，灭门主角家族的嫌疑
  - 幽冥教：幕后黑手，真正的敌人
- **妖族**（中立）
  - 九尾狐族：可合作但有条件
  - 龙族：高傲，一般不插手人族事务

## 四、历史背景

| 时间 | 事件 | 影响 |

| 十年前 | 主角家族被灭 | 主角踏上复仇之路 |

## 五、禁忌与代价

### 5.1 绝对禁忌

- 禁止凡人知晓修仙者存在（违者抹杀）
- 禁止修炼禁术《血神经》（违者遭天谴）
- 禁止跨界传送（通道封闭后）

### 5.2 力量代价

- 境界突破失败会修为倒退
- 借用外力会留下暗伤
- 过度修炼会损伤根基
