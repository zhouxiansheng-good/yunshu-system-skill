# 全书总纲（L1）

## 一、基础信息

| 项目 | 内容 |
|------|------|
| **书名** | 《逆天改命》 |
| **类型** | 玄幻 |
| **一句话梗概** | 废灵根少年林风为报家族灭门之仇，以燃烧寿命为代价获得逆天力量，最终打破命运束缚 |
| **目标总字数** | 200万字 |
| **预计卷数** | 4卷 |

## 二、核心卖点

| 卖点 | 说明 | 兑现方式 |
|------|------|---------|
| **爽点 1** | 废柴逆袭，打脸曾经嘲笑他的人 | 第10章、第30章 |
| **爽点 2** | 独特金手指：燃烧寿命换修为，越战越强 | 第1章获得，持续兑现 |
| **爽点 3** | 悬念钩子：灭门真凶到底是谁？ | 第50章揭示 |

## 三、四幕结构

### 第一幕：起（开局建局）

| 项目 | 内容 |
|------|------|
| **核心任务** | 主角进入故事，建立读者认同 |
| **关键事件** | 家族灭门，主角获得系统 |
| **主要冲突** | 与灭门凶手的初次交锋 |
| **阶段成果** | 主角站稳脚跟，读者知道"这书讲什么" |
| **章节范围** | 第1-50章 |

### 第二幕：承（冲突升级）

| 项目 | 内容 |
|------|------|
| **核心任务** | 升级冲突，扩大舞台 |
| **关键事件** | 进入青云宗，发现灭门背后有更大阴谋 |
| **主要冲突** | 与血魔宗的对抗 |
| **阶段成果** | 主角成长，势力扩张 |
| **章节范围** | 第51-150章 |

### 第三幕：转（重大反转）

| 项目 | 内容 |
|------|------|
| **核心任务** | 颠覆认知，最大危机 |
| **关键事件** | 发现系统本身就是阴谋的一部分 |
| **最大危机** | 主角失去系统，寿命将尽 |
| **阶段成果** | 主角蜕变，找到真正的敌人 |
| **章节范围** | 第151-250章 |

### 第四幕：合（终局收束）

| 项目 | 内容 |
|------|------|
| **核心任务** | 解决所有冲突，完成角色弧光 |
| **最终决战** | 与幕后黑手（天道）的决战 |
| **结局状态** | 打破系统束缚，真正逆天改命 |
| **余波伏笔** | 新的天道诞生，可用于续作 |
| **章节范围** | 第251-300章 |

## 四、主线任务链

### 4.1 长期目标

打破"废灵根不能修仙"的天道规则，为家族复仇，证明自己。

### 4.2 中期目标

| 阶段 | 目标 | 完成标志 |
|------|------|---------|
| 第一卷结束 | 站稳脚跟 | 建立自己的小势力 |
| 第二卷结束 | 声名鹊起 | 在区域内有话语权 |
| 第三卷结束 | 真相大白 | 知道敌人是谁 |

### 4.3 短期目标

**当前卷目标**：获得系统，完成第一次突破，开始复仇第一步。

## 五、角色成长弧线

### 5.1 主角弧光

| 阶段 | 内心状态 | 外在表现 |
|------|---------|---------|
| 开局 | 自卑、愤怒 | 被动应对 |
| 中期 | 坚定、自信 | 主动出击 |
| 后期 | 通透、豁达 | 掌控全局 |

### 5.2 关键关系演变

| 关系 | 开局 | 中期 | 结局 |
|------|------|------|------|
| 林风-反派 | 素不相识 | 势不两立 | 相互理解 |
| 林风-盟友 | 互相利用 | 生死与共 | 并肩作战 |

## 六、防跑偏约束

### 6.1 不可更改项

- [x] 世界底层规则：天道有缺，渡劫九死一生
- [x] 人设核心动机：只为保护家人和复仇
- [x] 终局方向：必须打破系统束缚才能胜利

### 6.2 可调整项

- [x] 支线节奏
- [x] 次要角色出场顺序
- [x] 具体打斗场面设计
