# 金手指设定

## 一、金手指基础信息

| 项目 | 内容 |
|------|------|
| **名称** | 逆天改命系统 |
| **类型** | 系统型 |
| **获取方式** | 家族灭门之夜，濒死时自动绑定 |
| **初始形态** | 一个半透明的面板，只有基础功能 |
| **完全形态** | 与主角灵魂融合，不再需要面板 |

## 二、核心功能

### 2.1 主要能力

- **功能**：燃烧寿命换取修为突破
- **限制**：
  - 每天最多燃烧10年寿命
  - 不能跨越大境界突破（如炼气不能直接到金丹）
  - 燃烧后进入24小时虚弱期
- **代价**：
  - 直接消耗寿命（主角初始寿命100年）
  - 频繁使用会损伤根基，影响未来上限
  - 寿命低于10年时，系统会强制休眠
- **成长路线**：
  - 初期：只能燃烧寿命换修为
  - 中期：可以燃烧寿命换技能熟练度
  - 后期：可以燃烧寿命推演未来（预知）

### 2.2 功能解锁节奏

| 阶段 | 解锁功能 | 章节 | 触发条件 |
|------|---------|------|---------|
| 初期 | 燃烧寿命换修为 | 第1-30章 | 自动拥有 |
| 中期 | 燃烧寿命换技能 | 第31-100章 | 完成系统任务：复仇第一步 |
| 后期 | 燃烧寿命推演未来 | 第101章+ | 寿命剩余不足30年 |

## 三、限制与代价

### 3.1 硬限制

- [x] 每天最多燃烧10年寿命
- [x] 不能跨越大境界突破
- [x] 燃烧后24小时虚弱期

### 3.2 软限制

- [x] 需要特定环境才能突破（如：雷劫需要开阔地）
- [x] 突破时有概率失败（与根基损伤程度相关）
- [x] 效果受环境影响（灵气稀薄处效率低）

### 3.3 代价

- [x] 直接消耗寿命
- [x] 频繁使用损伤根基
- [x] 寿命低于10年系统强制休眠

## 四、成长路线

### 4.1 升级条件

| 当前等级 | 升级条件 | 升级后变化 |
|---------|---------|-----------|
| Lv.1 | 自动 | 基础功能：燃烧寿命换修为 |
| Lv.2 | 完成复仇第一步 | 新增：燃烧寿命换技能熟练度 |
| Lv.3 | 寿命剩余不足30年 | 新增：燃烧寿命推演未来 |

### 4.2 与主线的关联

- 灭门之仇 → 需要力量 → 燃烧寿命换修为 → 变强但寿命减少 → 更急迫复仇 → 需要更多力量 → 恶性循环
- 最终打破循环：找到不消耗寿命的修炼方式，真正"逆天改命"

## 五、使用规范

### 5.1 允许使用场景

- [x] 绝境保命时
- [x] 关键突破时
- [x] 复仇之战时

### 5.2 禁止使用场景

- [x] 不能用来秒杀高于自己两个境界的敌人
- [x] 不能无限刷修为（有每日上限）
- [x] 不能改变已发生的重大事件

## 六、反制手段

| 反制类型 | 说明 | 示例 |
|---------|------|------|
| 探测型 | 能发现系统异常 | 高阶修士的神识扫描 |
| 封印型 | 能暂时封印系统 | 特殊阵法/禁制 |
| 代价型 | 让使用者付出更大代价 | 强制透支生命力 |
