## 一、场景规划

### 场景 1：灭门

| 项目 | 内容 |
|------|------|
| **地点** | 林家大宅 |
| **时间** | 深夜，月圆之夜 |
| **在场角色** | 林风（主角）、林家族人（背景）、黑衣人（反派） |
| **场景目标** | 建立冲突，制造悲剧，让读者同情主角 |
| **动作推进** | 林风被父亲藏入密室→听到外面屠杀声→冲出去看到满地尸体→被黑衣人发现并重伤 |
| **五感细节** | 视觉：火光冲天，血流满地；听觉：惨叫声、刀剑碰撞声；嗅觉：血腥味、烧焦味 |
| **情绪基调** | 恐惧→绝望→愤怒 |
| **出场伏笔** | 父亲临终前塞给林风一块令牌（F002） |
| **信息释放** | 林家被灭门，主角是唯一的幸存者 |

### 场景 2：觉醒

| 项目 | 内容 |
|------|------|
| **地点** | 林家废墟 |
| **时间** | 灭门后一小时，天快亮了 |
| **在场角色** | 林风（濒死） |
| **场景目标** | 获得金手指，给读者希望 |
| **动作推进** | 林风濒死→意识模糊中听到系统提示音→绑定"逆天改命系统"→用最后寿命换取修为突破→击杀剩余敌人 |
| **五感细节** | 触觉：冰冷地面，伤口剧痛；视觉：系统面板发出微光；听觉：系统冰冷的提示音 |
| **情绪基调** | 绝望→希望→疯狂 |
| **出场伏笔** | 系统提示"宿主寿命剩余：89年"（暗示代价） |
| **信息释放** | 系统功能：燃烧寿命换修为；主角当前寿命：89年 |

## 四、写作要点

### 4.1 必须兑现的内容

- [x] 主角必须展示从绝望到获得希望的心理转变
- [x] 必须埋下林家令牌的伏笔
- [x] 必须展示系统的代价（燃烧寿命）

### 4.2 必须避免的问题

- [x] 不要出现AI套路词（"眼中闪过一丝"等）
- [x] 不要过度描写血腥场面，点到为止
- [x] 不要解释系统原理，保持神秘感

### 4.3 风格要求

| 项目 | 要求 |
|------|------|
| **句长** | 短句为主，紧张场景3-8字 |
| **对话** | 口语化，禁止书面语 |
| **情绪** | 外化表现，禁止"他感到" |
| **结尾** | 硬截断，动作或对话收尾 |
