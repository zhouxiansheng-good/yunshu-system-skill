# 项目设定组件

**Trigger**: "开新书"/"初始化项目"/"创建小说项目"/"新建作品"

**核心理念**: 半自动。用户提供信息，AI按模板格式化并创建文件。AI不编造任何设定内容。

---

## 硬规则

1. **禁止AI编造内容**：所有设定内容必须由用户提供，AI只负责格式化和创建文件
2. **一个信息→一个文件**：用户提供一份完整信息，AI创建一个对应文件
3. **等用户提供后再创建**：AI先展示模板结构，等用户提供内容后再创建文件
4. **AI可以提问引导**：AI可以问"请提供XX信息"，但不能自己编答案
5. **AI可以建议补充**：AI可以建议"你可能还需要考虑XX"，但必须等用户确认

---

## 前置条件

- 无。本组件可独立运行，是整套技能的第一入口。

## 执行流程

### Step 1：收集项目基础信息

用 AskUserQuestion 逐项收集：

| 项目 | 收集方式 |
|------|---------|
| 项目根目录路径 | 用户直接输入 |
| 作品名称 | 用户直接输入 |
| 类型/流派 | AskUserQuestion选择 |
| 子类型 | AskUserQuestion选择 |
| 目标字数 | 用户直接输入 |
| 目标平台 | AskUserQuestion选择 |
| 一句话梗概 | 用户直接输入 |

**AskUserQuestion格式要求**：
- label放核心信息（1-5字），description放补充说明
- 不要把重要内容只放description

### Step 2：创建项目骨架

只创建文件夹结构和空的基础文件，不填入任何设定内容。

### Step 3：逐项创建设定文件（半自动）

**流程模式**：展示模板结构 → 用户提供内容 → AI格式化并创建文件

#### 3.1 世界观（必填）

1. AI展示模板结构（读取 `templates/02_世界观设定.md` 的标题和字段名）
2. AI问："请提供世界观设定，包括核心规则、力量体系、世界基础设定、禁忌与代价"
3. **用户口述或文字输入世界观内容**
4. AI将用户内容按模板格式化，写入 `{project_root}/设定/世界观.md`
5. AI确认："世界观已创建，是否需要修改？"

#### 3.2 人物角色（必填，一个角色一个文件）

1. AI问："请提供第一个角色的信息"
2. **用户提供角色信息**（姓名/年龄/身份/性格/术式/关系等）
3. AI按模板格式化，写入 `{project_root}/角色/{角色名}.md`
4. AI问："是否继续添加角色？"
5. 重复2-4直到用户说不需要

#### 3.3 可选设定（根据类型询问）

AI用 AskUserQuestion 询问：

| 设定项 | 触发条件 |
|--------|---------|
| 金手指 | 系统流/玄幻/都市等 |
| 修炼体系 | 玄幻/仙侠/武侠等 |
| 地图与世界 | 多地图/多世界等 |
| 势力设定 | 有宗门/组织/国家等 |

用户选择需要后，按同样的"展示模板→用户提供内容→AI格式化创建"流程执行。

### Step 4：创建总纲（半自动）

1. AI读取用户已创建的所有设定文件
2. AI基于设定生成总纲框架（只有结构，不编造剧情）
3. **用户补充或修改总纲内容**
4. AI格式化后写入 `{project_root}/大纲/总纲.md`
5. 用户确认

### Step 5：输出初始化报告

列出已创建的文件清单，建议下一步操作。

## 交互规范

### AskUserQuestion使用

```json
{
  "question": "请选择小说类型",
  "header": "类型选择",
  "options": [
    {"label": "玄幻", "description": "修仙、武侠、奇幻等"},
    {"label": "都市", "description": "现代背景，异能/系统/重生等"},
    {"label": "同人/综漫", "description": "穿越到已有作品世界"},
    {"label": "科幻", "description": "未来世界，星际/末世/机甲"}
  ],
  "multiSelect": false
}
```

### 收集用户内容的方式

- **选择型信息**：用 AskUserQuestion（类型、平台等）
- **输入型信息**：让用户直接口述或文字输入（梗概、设定细节等）
- **不要用 AskUserQuestion 收集长文本**，选择框不适合长内容
