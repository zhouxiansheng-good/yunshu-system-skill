# 角色状态机与角色卡指南

> 触发：正文写作完成后自动执行

## 架构

```
正文写作 → 提取变化 → 更新细纲人物卡 → 同步到角色卡Markdown
     ↑                                        ↓
     └──────── 写作时注入当前章角色状态 ←─────────┘
```

## 大纲版 vs 细纲版

| 维度 | 大纲版角色卡 | 细纲版角色卡 |
|------|-------------|-------------|
| 位置 | `角色/角色名.md` | `记忆账本/角色状态追踪.md` |
| 数量 | 每个角色1张 | 每章每角色1条记录 |
| 状态格式 | 起点→终点弧线 | 上一章→本章变迁 |
| 更新时机 | 手动/大版本更新 | 每章写完后自动更新 |
| 用途 | 把握角色整体弧线 | 写正文时的即时参照 |

## 每章更新流程

1. 从正文提取角色变化
2. 按关键词分类更新：

| 变化关键词 | 更新维度 |
|-----------|---------|
| 来到/前往/回到/离开/抵达 | 当前位置 |
| 受伤/重伤/中毒/恢复/昏迷 | 身体状态 |
| 突破/晋升/领悟/觉醒/修为 | 修为状态 |
| 得到/获得/丢失/丢弃/使用 | 持有物品 |
| 信任/怀疑/敌对/合作/背叛 | 人际关系 |

3. 在角色状态追踪中用→标记变迁
4. 同步到角色卡（更新终点值）

## OOC检测

| 检查点 | 严重度 | 处理 |
|--------|--------|------|
| OOC红线违规 | HIGH | 重写该段 |
| 修为状态矛盾 | HIGH | 修改行为或更新状态 |
| 人际关系矛盾 | MEDIUM | 过渡或修改 |
| 经济状态矛盾 | MEDIUM | 修改或更新 |

评分：10=完美 / 7-9=轻微 / 4-6=明显OOC / 0-3=严重OOC

**通过标准：>=7 且无 HIGH**
