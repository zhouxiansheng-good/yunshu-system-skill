# 伏笔追踪指南

## 伏笔状态

| 状态 | 图标 | 含义 |
|------|------|------|
| PLANTED | 🟡 | 已埋设，等待回收 |
| RESOLVED | 🟢 | 已回收 |
| OVERDUE | 🔴 | 超期未回收（>=15章） |

## 伏笔重要度

| 重要度 | 回收要求 |
|--------|---------|
| HIGH | 必须回收，不得遗忘 |
| MEDIUM | 尽量回收 |
| LOW | 可遗忘但需记录 |

## 操作流程

### 埋设伏笔

写正文时自然埋设，写完后在 `记忆账本/伏笔追踪.md` 登记：
1. 分配ID（F001, F002, ...）
2. 记录描述、埋设章节、重要度、暗示文本、关联角色

### 回收伏笔

正文中自然回收后，更新伏笔追踪表：
1. 找到对应ID → 状态改为 RESOLVED
2. 记录回收章节和回收文本
3. 计算埋设-回收跨度

### 检查超期（每5章）

1. 扫描所有 PLANTED 状态伏笔
2. 当前章节 - 埋设章节 >= 15 → 标记 OVERDUE
3. HIGH 重要度超期伏笔 → 优先安排回收

### 查询活跃伏笔（写正文前）

1. 查询所有 PLANTED 和 OVERDUE 伏笔
2. 重点关注近10章内埋设的伏笔
3. 近2章内回收的伏笔也需关注（避免矛盾）

## 伏笔埋设技巧

| 方法 | 说明 |
|------|------|
| 对话暗示 | 角色无意间提到相关信息 |
| 环境叙事 | 场景中放置相关线索 |
| 行为异常 | 角色反常行为暗示隐情 |
| 物品伏笔 | 重要物品提前出场 |
| 预言/传说 | 通过预言暗示未来事件 |

## 禁忌

- 🚫 代码式标记出现在正文中
- 🚫 过于刻意的暗示
- 🚫 同一章埋设过多伏笔（每章最多2-3条）
- 🚫 HIGH 重要度伏笔超过15章不回收

## 统计指标

| 指标 | 计算方式 | 健康值 |
|------|---------|--------|
| 未回收数 | PLANTED + OVERDUE | <= 总数50% |
| 超期数 | OVERDUE | 0 |
| 高重要度未回收 | HIGH & 未回收 | <= 2 |
| 回收率 | RESOLVED / 总数 | >= 50% |
