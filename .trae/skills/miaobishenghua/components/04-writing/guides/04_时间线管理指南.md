# 时间线管理指南

## 时间线事件维度

| 维度 | 说明 | 示例 |
|------|------|------|
| 事件ID | 唯一标识 | E001 |
| 章节 | 发生章节 | 第5章 |
| 日期标签 | 故事内日期 | 第一天 / 建元三年春 |
| 相对时间 | 当天内时间 | 清晨 / 午后 / 深夜 |
| 描述 | 事件内容 | 主角抵达青云宗 |
| 涉及角色 | 参与角色 | 林风、苏婉 |
| 地点 | 事件发生地 | 青云宗山门 |
| 持续时间 | 事件时长 | 半个时辰 |

## 地点距离管理

新地点出现时，记录到其他地点的距离和交通方式：

```markdown
### 青云宗
- → 天都城：三天马程 / 一天飞行
- → 魔渊：七天步行 / 两天飞行
```

## 操作流程

### 登记事件（每章写完后）

在 `记忆账本/时间线.md` 登记：分配事件ID → 记录章节/日期/时间/描述/角色/地点 → 按章节和时间排序

### 登记地点（新地点出现时）

记录地点名称和描述 → 记录到已知地点的距离 → 标注交通方式

### 一致性检查（每5章）

| 检查点 | 严重度 | 方法 |
|--------|--------|------|
| 距离矛盾 | HIGH | 对比移动路径和地点距离表 |
| 时序矛盾 | MEDIUM | 检查日期标签是否递增 |
| 角色位置矛盾 | HIGH | 对比同一日期内不同角色位置 |

评分：10=完美 / 7-9=轻微 / 4-6=明显矛盾 / 0-3=严重混乱

**通过标准：>=7 且无 HIGH**
