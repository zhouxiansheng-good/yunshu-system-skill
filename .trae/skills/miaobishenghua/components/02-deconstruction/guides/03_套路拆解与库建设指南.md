# 套路拆解与库建设指南

---

## 套路定义

套路 = 经过验证的情节模式，包含：触发条件 → 发展阶段 → 高潮设计 → 收尾方式。

拆解目的：提取可复用的情节骨架，不是复制具体剧情。

---

## 套路分类体系

### 按功能分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 开局套路 | 开篇吸引读者的模式 | 废柴逆袭、强者回归、隐藏身份、系统降临 |
| 情节套路 | 推动剧情发展的核心桥段 | 打脸、装逼、升级突破、英雄救美 |
| 环境套路 | 场景切换与地图推进 | 换地图、秘境探险、宗门大比 |
| 社交套路 | 人际关系建立与发展 | 收小弟、建立势力、收女主 |
| 对抗套路 | 冲突设计与反派处理 | 反派套路、复仇套路、生死战 |
| 结构套路 | 整体叙事框架 | 三幕式、英雄之旅、单元剧、螺旋上升 |

### 按情绪分类

| 类型 | 核心情绪 | 示例 |
|------|---------|------|
| 爽感套路 | 痛快、满足 | 打脸、装逼、逆袭 |
| 紧张套路 | 悬念、压迫 | 被追杀、限时任务、身份暴露危机 |
| 温情套路 | 感动、共鸣 | 师徒情深、兄弟义气、守护 |
| 悲怆套路 | 悲壮、牺牲 | 献祭换力量、背水一战、生离死别 |
| 反转套路 | 意外、震惊 | 身份反转、幕后黑手、误会解除 |

## 拆解维度

### 1. 骨架提取

```
套路名称：
所属分类：
核心逻辑：（一句话概括）

阶段分解：
- 触发条件：（什么情况下启动）
- 发展阶段：（每一步发生什么）
- 高潮设计：（爽点/转折点在哪里）
- 收尾方式：（如何结束，留下什么钩子）

情绪曲线：
[压抑] → [积累] → [爆发] → [余韵]
```

### 2. 变量识别

每个套路的可替换元素：
- **人物变量**：谁执行这个套路（主角/配角/反派）
- **场景变量**：在哪里发生（宗门/都市/秘境）
- **动机变量**：为什么发生（复仇/求生/利益）
- **结果变量**：带来什么后果（实力提升/关系变化/新危机）

### 3. 组合规则

- 单章套路：1个套路 = 1章内容
- 连环套路：2-3个套路串联 = 1个小高潮
- 嵌套套路：大套路套小套路 = 复杂情节
- 反套路：故意打破套路预期 = 新鲜感

## 拆解流程

### Step 1：识别套路

阅读参考小说时，标记以下信号：
- 情绪突变点（压抑→爆发）
- 熟悉的情节节奏
- 可预测的桥段走向

### Step 2：提取骨架

剥离具体剧情，保留结构：
- 删除角色名字 → 保留角色功能（主角/反派/配角）
- 删除具体场景 → 保留场景类型（宗门/都市/秘境）
- 删除具体对话 → 保留对话功能（挑衅/反击/震惊）

### Step 3：标注变量

标记该套路中所有可替换元素。

### Step 4：评估效果

- 爽感强度：1-5分
- 适用频率：高频/中频/低频
- 创新空间：大/中/小

### Step 5：入库

按套路库模板格式存入 `{project_root}/拆文分析/套路库/`。

## 套路与词汇的关系

| 维度 | 词汇/句式 | 套路 |
|------|----------|------|
| 作用 | 表达层面的素材 | 结构层面的骨架 |
| 使用时机 | 写正文时选用 | 写细纲时选用 |
| 选择逻辑 | 同类型内按权重排序 | 按场景+情绪匹配 |
| 存储位置 | `语句素材库/` | `套路库/` |

---

## 核心规则

1. 拆解的是骨架，不是剧情
2. 每个套路必须可变量化替换
3. 套路按功能+情绪双维度分类
4. 套路库独立存储，不与词汇库混用
5. 套路权重单独计算，不与词汇权重混用
