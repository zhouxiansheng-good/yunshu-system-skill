# 词汇偏好收集与排序系统

## 收集场景

### 场景一：AI 推荐 → 人类选择

AI 提供候选板，人类选择、修改或弃用。记录选择结果。

### 场景二：人类主动替换

人类说"把 X 改成 Y"，记录替换关系。

### 场景三：人类主动提供

人类直接给出"我喜欢用 XX 表达 YY"，记录进对应类型。

---

## 权重更新规则（类型隔离）

### 基础分

| 行为 | 分数变化 | 影响范围 |
|------|---------|---------|
| 被选中 | +2 | 同类型内 |
| 跨章节复用 | +3 | 同类型内 |
| 用户明确说"好" | +5 | 同类型内 |
| 连续 3 次被弃用 | -3 | 同类型内（不进入候选板） |
| 被禁用 | -100 | 同类型内（不进入候选板） |

### 防腻降权

| 近期使用频率 | 降权 |
|-------------|------|
| 本章已用 | -1 |
| 本卷已用 | -0.5 |
| 长期未用（>10章） | +1 |

---

## 排序逻辑（同类型内）

```
最终分数 = selected_count * 2 + reuse_count * 3 + like_score - recent_penalty

步骤：
1. 过滤禁用项
2. 按最终分数降序排列
3. 同分按使用频率排序
4. 每类至少提供3个不同分数段的选项
```
