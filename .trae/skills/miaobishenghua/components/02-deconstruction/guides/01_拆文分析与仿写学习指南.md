# 拆文分析与结构借鉴学习指南

## 两种模式

| 模式 | 范围 | 适用场景 |
|------|------|----------|
| 快速拆解（默认） | 黄金三章+整体结构 | 快速学习对标作品 |
| 深度拆解 | 逐章拆解整本小说 | 系统学习 |

## 拆书六原则

1. **有目的**：明确每次拆书目标（主线/人设/打斗/情绪等）
2. **有方法**：根据目的选择方法
3. **拆出理论**：结果必须系统性，不能只有零散心得
4. **摒弃好恶**：不喜欢的题材也要能拆出价值
5. **扬长避短**：拆优点学习，发现缺点引以为鉴
6. **拆自己喜欢的书**：激情满满效果最好

## 快速拆解流程

1. 确认拆解对象（书名+平台+重点方向）
2. 黄金三章拆解：

| 维度 | 检查点 |
|------|--------|
| 钩子 | 开篇用什么钩子？ |
| 人设 | 前3章建立了哪些人设？怎么建立的？ |
| 爽点 | 每章的爽点在哪？ |
| 悬念 | 章尾悬念怎么设计？ |
| 节奏 | 快慢如何交替？ |
| 信息量 | 前3章交代了多少设定？怎么做到不枯燥？ |

3. 整体结构拆解：故事线交织 / 人物架构 / 节奏地图 / 伏笔网络
4. 按 [references/output-templates.md](../references/output-templates.md) 模板输出

## 拆书核心方法

### 拆书流程

1. **概括**：一句话总结故事核心
2. **识别结构单元**：每个单元 = 起承转合 = 一个完整小圈，后一个比前一个更大
3. **抽离框架和情绪链条**：提取条件框架，不抄情节内容
4. **借鉴而非抄袭**：抄袭 = 直接抄情节内容；借鉴 = 抽离框架+情绪链条，自己填充血肉

### 条件框架提取法

《高武纪元》一段剧情提炼为三个条件：
1. 展露部分天赋的主角，还有隐藏天赋
2. 对主角进行争夺的两方势力
3. 利用信息差，一方略微看低主角，凸显另一方慧眼识珠

替换人物、背景、金手指后即可复用，只保留情绪相似。

### 抽象拆书五步法

1. 概括 → 2. 拆解为信息团（情绪转折点） → 3. 按情绪上行/下行/转折归类 → 4. 提取通用条件框架 → 5. 用素材填充框架

### 感情线拆书技巧

拆恋爱文要拆推进情感线的**框架和结构**，而非具体日常内容。

**双标法**：同一件事（送可乐），男配送 → 女主拒绝（减肥）；男主送 → 女主接受（需要补充糖分）。三要素：①差不多同一件事前后连续发生 ②女主态度截然不同 ③男主不清楚。

### 抄书学习法（仅限训练，不进入产出链路）

选择优秀小说原封不动抄写 → 感受故事走向、困境收获、伏笔衔接 → 记录节奏和功能观察 → 提炼成语料卡与结构卡。

注意：

- 手抄训练只用于培养感知，不用于产出正文
- 不把原文换皮后重新输出
- 最终进入项目的是"功能骨架"和"场景条件"，不是近似表达

## 错误拆书方式

| 错误 | 说明 |
|------|------|
| 拆"每段几百字的写作目的" | 真正要拆的是框架结构、情绪链条、核心梗运用方式 |
| 只拆一本对标书 | 至少5本同网站同题材同类型参考书，从中选一本对标 |
| 拆大神的书当对标 | 大神有不可复制的个人风格和笔力。新人应找精品到万订之间的书 |
| 对标书跨网站 | 不同网站读者群体不同，跨网站对标容易踩雷 |

对标书选择流程：广泛读同题材 → 定方向 → 定参考书（5-10本）→ 提炼结构共性

## 深度拆解流程

### 输出目录结构

```
{小说标题}/
├── 概要.md
├── 章节/（第N章_深度拆解.md + 第N章_摘要.md）
├── 角色/（{角色名}.md + 角色关系.md）
├── 剧情/（{剧情标题}.md + 故事线.md + 散落情节.md）
├── 设定/（世界观.md + 金手指.md）
├── 拆文报告.md
└── _progress.md
```

### 6阶段管道

| 阶段 | 输入 | 输出 |
|------|------|------|
| 0 | 原始文本 | 概要.md + 章节索引 |
| 1 | 前3章原文 | 第1-3章_深度拆解.md |
| 2 | 分块章节文本 | 章节摘要.md |
| 3 | 全部章节摘要 | 剧情/*.md + 故事线.md |
| 4 | 阶段3合并后角色数据 | 设定/*.md + 角色/*.md |
| 5 | 全部输出 | 拆文报告.md |

### 原子提取六大铁律

1. 绝对按时间顺序排列
2. 只用客观白描，不用叙事框架词
3. 信息保真，不遗漏改变语境的细节
4. 高度浓缩，一个情节点一句话
5. 复合动作要合并
6. 信息点提取客观事实，不做叙事分析

### 质量阈值

| 指标 | 阈值 | 不达标处理 |
|------|------|------------|
| 置信度 | >= 0.85 | 低于0.85标记「待复核」 |
| 覆盖率 | 85%-95% | <85%触发孤立情节二次分类 |
| 重叠率 | <= 35% | >35%提示边界模糊，建议合并 |

### 分块策略

| 规模 | 策略 |
|------|------|
| <100章 | 按阶段整体处理 |
| 100-500章 | 按5-8章分块 |
| >500章 | 先按卷分组，卷内再按5-8章分块 |

### 恢复机制

启动时检查输出目录是否已有 `_progress.md`，有则从断点恢复。

## 短篇拆解

聚焦情绪曲线和反转设计：
1. 确认对象 + 题材路由（加载 [references/genre-frameworks-unified.md](../references/genre-frameworks-unified.md)）
2. 全篇结构拆解
3. 情绪曲线分析
4. 反转设计分析
5. 开头与结尾分析
6. 输出拆文报告

## 边界说明

- 本指南的目标是拆出结构、情绪链条、功能模块和语料标签
- 本指南不鼓励按参考文本"仿写开头""仿写章尾""重写原段"
- 任何可进入项目的内容都必须先抽象化，再经过人工判断后使用
