## 权重系统

### 核心规则

1. 每类语料独立排序，权重不跨类型影响
2. 同一类型内，按权重分数竞争排序
3. 权重只存储在语句素材库的分类文件中，不写入记忆账本

### 权重字段

```
phrase_id: 唯一标识
content: 语料内容
source: 来源（拆解/原创/修改）
tags: [场景, 功能, 风格]
scores:
  selected_count: 被选中次数（+2/次）
  reuse_count: 跨章节复用次数（+3/次）
  like_score: 用户主观评分 (-5 ~ +5)
  recent_hit: 近期使用频率（>3次适当降权）
flags:
  ban: 是否禁用（禁用后不进入候选板）
```

### 排序算法（同类型内）

```
最终分数 = selected_count * 2 + reuse_count * 3 + like_score - recent_penalty

recent_penalty:
  - 近期使用（本章）：-1
  - 近期使用（本卷）：-0.5
  - 长期未使用（>10章）：+1

排序步骤：
1. 过滤禁用项（ban=true）
2. 按最终分数降序排列
3. 同分按使用频率排序
4. 每类至少提供3个不同分数段的选项
```

## 执行流程

### Step 1：前置检测

检查项目是否已初始化。

### Step 2：获取文本

- 用户提供文本：直接读取
- 用户提供链接：尝试下载/抓取
- 用户提供书名：引导用户提供文本或链接

### Step 3：拆解分析

| 维度 | 拆解内容 | 存储位置 |
|------|---------|---------|
| **词汇** | 情绪词、动作词、环境词、对话词、神态词、术语词 | `语句素材库/01-10/` |
| **句式** | 短句、长句、问句、留白句、动作句、心理句、对白句 | `语句素材库/10_修辞句式/` |
| **段落** | 打斗段、描写段、转场段、对话段、情绪段 | `拆文库/` |
| **结构** | 钩子、爽点、转折、收束 | `拆文库/` |
| **情绪** | 紧张、轻松、压抑、激昂、悲伤 | `语句素材库/03_写情/` |
| **套路** | 开局套路、情节套路、环境套路、社交套路、对抗套路、结构套路 | `套路库/` |

### Step 4：分类归档

| 分类维度 | 示例 | 存储位置 |
|---------|------|---------|
| **按功能** | 写人、写景、写情、写动作、写神态、写心理、写对话、写氛围、五感、修辞 | `语句素材库/01-10/` |
| **按场景** | 初见、试探、冲突、暧昧、反转、和解、爆发 | 在各类别内细分 |
| **按风格** | 冷感、俏皮、克制、狠厉、轻松、压抑 | 在各类别内标注 |
| **套路功能** | 开局、情节、环境、社交、对抗、结构 | `套路库/01-06/` |
| **套路情绪** | 爽感、紧张、温情、悲怆、反转 | 在套路库内标注 |

### Step 5：套路拆解

调用 `guides/03_套路拆解与库建设指南.md`

1. 识别套路：标记情绪突变点和熟悉桥段
2. 提取骨架：剥离角色名、具体场景、具体对话，保留结构
3. 标注变量：人物变量、场景变量、动机变量、结果变量
4. 评估效果：爽感强度、适用频率、创新空间
5. 入库：按套路库模板存入 `套路库/`

### Step 6：权重初始化

每条语料初始权重为0，后续根据使用情况在同类型内调整。

### Step 7：更新索引

在项目根目录创建/更新 `拆文分析/README.md`，建立多维度索引。

## 核心规则

1. 每类语料独立排序，权重不跨类型影响
2. 支持按功能、场景、风格多维度检索
3. 每条语料有权重分数，高优先级的优先推荐（同类型内）
4. 多本书的拆解内容合并到同一资料库
5. 拆解的是"功能骨架"和"表达方式"，不是具体剧情
6. 每个项目的拆文资料库独立
7. 权重只存储在语句素材库和套路库中，不写入记忆账本
8. 套路与词汇独立存储、独立计算权重、独立调用
