## 套路条目格式

```markdown
### 套路ID：TXXX

- **套路名称**：
- **所属分类**：（开局/情节/环境/社交/对抗/结构）
- **情绪类型**：（爽感/紧张/温情/悲怆/反转）
- **核心逻辑**：（一句话概括）

#### 阶段分解

| 阶段 | 内容 | 功能 |
|------|------|------|
| 触发条件 | | 启动套路的前提 |
| 发展阶段1 | | 铺垫/积累 |
| 发展阶段2 | | 推进/升级 |
| 高潮设计 | | 爽点/转折点 |
| 收尾方式 | | 结束+留钩子 |

#### 情绪曲线

```
[    ] → [    ] → [    ] → [    ]
 触发    积累     爆发     余韵
```

#### 变量表

| 变量 | 说明 | 示例 |
|------|------|------|
| 人物变量 | | |
| 场景变量 | | |
| 动机变量 | | |
| 结果变量 | | |

#### 评估

- **爽感强度**：/5
- **适用频率**：高频 / 中频 / 低频
- **创新空间**：大 / 中 / 小

#### 来源

- **出处**：《书名》第X章
- **备注**：
```

## 权重字段

```yaml
routine_id: TXXX
name: 套路名称
category: 功能分类
emotion: 情绪类型
core_logic: 核心逻辑
stages:
  trigger: 触发条件
  development: [阶段1, 阶段2]
  climax: 高潮设计
  ending: 收尾方式
emotion_curve: [触发, 积累, 爆发, 余韵]
variables:
  character: 人物变量
  scene: 场景变量
  motivation: 动机变量
  result: 结果变量
scores:
  selected_count: 被选中次数（+2/次）
  reuse_count: 跨章节复用次数（+3/次）
  like_score: 用户主观评分 (-5 ~ +5)
  recent_hit: 近期使用频率（>3次适当降权）
  thrill_score: 爽感强度 (1-5)
  frequency: 适用频率 (high/mid/low)
  innovation: 创新空间 (large/mid/small)
flags:
  ban: 是否禁用
source:
  book: 出处书名
  chapter: 章节
  notes: 备注
```

## 排序算法（同类型内）

```
最终分数 = selected_count * 2 + reuse_count * 3 + like_score + thrill_score * 2 - recent_penalty

recent_penalty:
  - 近期使用（本章）：-1
  - 近期使用（本卷）：-0.5
  - 长期未使用（>10章）：+1

排序步骤：
1. 过滤禁用项（ban=true）
2. 按最终分数降序排列
3. 同分按使用频率排序
4. 每类至少提供3个不同分数段的选项
```
