# 妙笔生花 - 半自动小说工作台

**架构**: 五组件联动（设定→拆文→细纲→正文→可视化）

**核心理念**: 半自动。用户提供信息，AI格式化、辅助检查、生成提示词和正文。AI不编造设定和细纲内容。

---

## 半自动硬规则（全局）

1. **禁止AI编造设定内容**：世界观、人物、金手指、修炼体系等设定必须由用户提供
2. **禁止AI编造细纲内容**：出场人物、事件、冲突、情绪走向必须由用户提供
3. **一个信息→一个文件**：用户提供一份完整信息，AI创建一个对应文件
4. **等用户提供后再操作**：AI先问→用户回复→AI再执行
5. **AI只做三件事**：格式化、辅助检查、生成（提示词/正文）
6. **AI可以建议补充**：如"你可能还需要考虑XX"，但必须等用户确认

| 组件 | 名称 | 功能 | 前置条件 | 调用地址 |
|------|------|------|---------|---------|

| **组件四** | 正文生成 | AI读取细纲+设定生成正文，质检+AI味清理 | 需先运行组件一、三 | `components/04-writing/SKILL.md` |
| **组件五** | 可视化拓扑 | 可视化编辑人物/事件/世界观关系拓扑图 | 需先运行组件一 | `components/05-visualization/SKILL.md` |

## 核心工作流

```
开新书
  ↓
组件一：项目设定（用户主导）
  - 确定世界观（必填）
  - 确定人物角色（必填）
  - 确定金手指（可选，根据类型）
  - 确定修炼体系（可选，根据类型）
  - 确定地图/世界（可选，根据类型）
  - 生成总纲
  ↓
组件二：拆文分析（可多次执行）
  - 拆解参考小说
  - 构建语句素材库
  - 构建套路库
  ↓
组件三：细纲写作（用户主导）
  Step 1: 用户写细纲核心内容
    - 出场人物
    - 事件/冲突
    - 情绪走向
  Step 2: AI读取设定+前文，辅助补充
    - 伏笔检查
    - 连续性检查
    - 角色状态检查
  Step 3: 生成细纲提示词+正文提示词
  Step 4: 用户确认
  ↓
组件四：正文生成
  Phase 1: 生成正文草稿
  Phase 2: AI味检测+标记+建议替换
  Phase 3: 词汇替换参考
  Phase 4: 用户确认定稿
  Phase 5: 后置流程（自动）
    - 质检报告
    - 角色状态更新
    - 时间线登记
    - 伏笔状态更新
    - 资料库权重更新
  ↓
组件五：可视化拓扑（按需启动）
  - 查看人物关系网络
  - 标记悬疑点/反转点/高潮
  - 与文档双向同步
```

## 全局约束

1. 技能目录只保留模板和定义，不存项目数据
2. 所有项目数据放在项目根目录
3. 设定和细纲由用户主导，AI辅助不替代
4. 权重按类型隔离，不跨类型影响
5. 权重只存储在语句素材库中，不写入记忆账本
6. 后置触发顺序：质检→角色状态更新→时间线登记→伏笔状态更新→资料库权重更新
7. AI味检测：自动检测+标记+建议替换，用户确认后执行

## 交互规范（AskUserQuestion使用规则）

### 选项格式规范

```json
{
  "question": "问题文本",
  "header": "简短标题",
  "options": [
    {"label": "选项标题", "description": "补充说明"},
    {"label": "选项标题", "description": "补充说明"}
  ],
  "multiSelect": false
}
```

### 关键规则

| 字段 | 用途 | 要求 |
|------|------|------|
| **label** | 选项标题栏，用户点击的目标 | 简短明确，1-5个字，必须包含核心信息 |
| **description** | 选项下方补充说明 | 可选，仅作辅助，不要把重要内容只放这里 |
| **question** | 问题文本 | 明确具体，不要模糊 |
| **header** | 简短标题 | 3-5个字概括问题 |

### 错误示例 vs 正确示例

**错误**（内容放description，label无法选择）：
```json
{"label": "时间", "description": "现代日本（咒术回战原作时间线）2018年左右"}
```

**正确**（核心内容放label，description辅助）：
```json
{"label": "现代日本（2018年）", "description": "咒术回战原作时间线"}
```
